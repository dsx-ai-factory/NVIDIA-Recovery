# Claude Code Repository Guide

Claude Code imports the repository-level `AGENTS.md` above. Treat it as the
canonical project guide.

If a nested `AGENTS.md` exists in the path you are editing, apply it with the
same directory scope and precedence that Claude Code would normally apply to a
nested `CLAUDE.md`.

If you find a nested `CLAUDE.md`, replace it with an `AGENTS.md` file in the
same directory and keep this root shim as the only `CLAUDE.md` in the
repository.
