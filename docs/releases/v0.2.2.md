# NVIDIA Recovery v0.2.2

Proposed source/Helm release; not published or qualified for public launch.

- Source and Helm distribution with versioned notes and SHA-256 checksums.
  Operators build images from the same source revision in their own registry.
- Public defaults omit the optional NVIDIA Attribution provider. Explicit private
  provider enablement remains separately configured and qualified.
- Advice Operator is excluded. Existing users must assess their migration before
  upgrading; its controller/CRDs are not a supported release path.
- Public API documentation covers Gateway HTTP/gRPC and the Attribution Adapter
  contract. This packaging change introduces no API/schema behavior change.

Use the [release procedure](../../RELEASE.md) and matching build/deployment guides.
Set chart image references to images built from this source; chart `appVersion`
is the `v`-prefixed release version.

Before publication, maintainers must finish these release-specific fields:

- Reviewed PR range, public API/configuration changes and migration steps.
- Exact-source public code-check and build-input availability evidence.
- Dependency vulnerability findings and fixes or accepted exceptions; license
  review including the chart's bundled AGPLv3 MinIO material.
- Effective repository/environment approvals and distribution visibility.

Archive identity/checksums are emitted in `release.json` and `SHA256SUMS`.
Local Helm lint/render is not runtime recovery qualification. Live recovery
qualification is excluded. Anonymous distribution, hosted docs and operator
image-build/install evidence remain unverified until separately recorded.
Secret scanning and removal are explicitly skipped, including cleanup, rotation
and history rewriting. Checksums are not chart signatures or a DSX readiness claim.
