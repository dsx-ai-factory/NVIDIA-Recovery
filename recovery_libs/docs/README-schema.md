This lib should have all the contract schema between services.

## Folder explain

* The `json_schema` folder has all the json schema definitions.

* The `shema` folder has all the schema classes.

* The `scripts` folder has all the scripts needed for generating the schema objects.

## How to use

* modify the json schema when needed.
* run the script `./scripts/generate.sh`
* import the class in your code.
